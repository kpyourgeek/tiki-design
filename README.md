# Tiki — App Design

Interactive prototype of **Tiki**, a mobile ticketing app for Algeria: discover events, buy with a Tiki balance, enter with a live QR ticket; hosts create events, manage gates and door staff, and get paid.

**Open it:** https://kpyourgeek.github.io/tiki-design/

- 17 screens (11 attendee, 6 organizer) and 14 shared components, all clickable
- Arabic right-to-left versions of Discover and Ticket
- "All screens" view and product notes in the sidebar
- One self-contained file (`index.html`, ~0.7 MB); opening it needs an internet connection for fonts and React
